# Sales Dashboard

## Overview
An interactive business intelligence dashboard built to visualize sales, profit, discount, and quantity trends. It enables users to explore performance across categories, regions, and time periods.

## Aim
To demonstrate how data visualization and storytelling can turn raw sales data into actionable insights.

## Technology Stack
- Python  
- Streamlit  
- Pandas  
- Plotly
