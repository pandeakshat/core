# Data Audit & Intelligence Tool

## Overview
A Streamlit application that audits datasets for quality, structure, and readiness for machine learning. It also provides automated insights and recommendations for data improvement.

## Aim
To simplify the data validation process and offer quick, actionable intelligence on any dataset.

## Technology Stack
- Python  
- Streamlit  
- Pandas  
- NumPy
