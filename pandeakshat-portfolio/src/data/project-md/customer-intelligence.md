# Customer Intelligence Hub

## Overview
The Customer Intelligence Hub unifies key customer analytics — churn prediction, segmentation, sentiment, and geospatial insights — into one modular dashboard. It provides a complete view of customer behavior and business opportunities using machine learning.

## Aim
To create a unified platform for customer-focused data intelligence and predictive insights that businesses can directly act on.

## Technology Stack
- Python  
- Streamlit  
- Scikit-learn  
- Plotly
